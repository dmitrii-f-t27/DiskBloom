DiskBloom 1.5 — macOS 14 or later, Apple silicon (M1 or newer)

INSTALLATION
Drag DiskBloom.app to Applications, then open it from Applications.
If you use the ZIP download, extract it first and move DiskBloom.app to Applications.

SIGNATURE
This release has an ad-hoc signature. It is not Developer ID signed or notarized
by Apple. macOS Gatekeeper may block the first launch. Follow the macOS prompt
and, only if you trust this download, use the per-app Open Anyway option in System
Settings > Privacy & Security. Do not disable system-wide security protections.

You can compare the download's SHA-256 checksum with the SHA256SUMS release file.
Apple's instructions: https://support.apple.com/102445

PRIVACY
DiskBloom has no analytics or telemetry, and its disk tools never use the network.
Only the optional assistant, if you connect an API, sends your questions and the
names, paths and sizes it looks up to the provider you chose. Nothing is deleted
permanently: reviewed items go to the Trash.
