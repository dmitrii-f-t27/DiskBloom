DiskBloom 1.3 — macOS 14 or later, Apple Silicon (M1 or newer)

INSTALLATION
Drag DiskBloom.app to Applications, then open it from Applications.
If using the ZIP download, extract it first and move DiskBloom.app to Applications.

SIGNATURE
This release has an ad-hoc signature. It is not Developer ID signed or notarized
by Apple. macOS Gatekeeper may block the first launch. Follow the macOS prompt
and, only if you trust this download, the per-app Open Anyway option in System
Settings > Privacy & Security. Do not disable system-wide security protections.

You can compare the download's SHA-256 checksum with the SHA256SUMS release file.
Apple's instructions: https://support.apple.com/102445

DiskBloom 1.3 — macOS 14 и новее, Apple Silicon (M1 и новее)

УСТАНОВКА
Перетащите DiskBloom.app в Applications («Программы») и откройте его оттуда.
При скачивании ZIP сначала распакуйте архив.

ПОДПИСЬ
Эта версия имеет локальную подпись ad-hoc. Она не подписана Developer ID
и не прошла нотариальную проверку Apple. macOS может заблокировать первый запуск.
Следуйте сообщению macOS; если доверяете загрузке, используйте разрешение запуска
именно этого приложения в «Системные настройки → Конфиденциальность и безопасность».
Не отключайте системную защиту целиком.

Контрольную сумму SHA-256 загрузки можно сверить с файлом SHA256SUMS в релизе.
Инструкция Apple: https://support.apple.com/102445
